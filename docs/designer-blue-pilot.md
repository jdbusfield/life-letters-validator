# Blue lowercase designer-file pilot

Source: Life Letters Cards LC v8 blue (1).pdf, 56 raster-art pages at 324 x 414 points (4.5 x 5.75 inches), 300 pixels per inch. Genuine transparent photo windows are preserved. Source SHA-256 is pinned in lib/designerBlueDeck.js. The original is stored privately at survey-pdfs/templates/blue-lowercase-v8-final.pdf; it contains no customer content and is outside customer retention prefixes.

All saved lowercase sets use the approved final designer renderer in their selected color. See `docs/designer-print-colors.md`. DESIGNER_BLUE_TEST_SURVEY_IDS is retained only by a compatibility helper and does not control production routing. No automatic Canva transfer or printing is enabled. A completed PDF is imported into Canva for review through the connected Canva tool.

Pages 1-4 retain the introductory artwork. Pages 5-56 alternate letter front/back from a to z, with qu for Q. Front photos are centered with their original proportions inside a safe rectangle measured from the genuine transparent window. The entire photo remains visible, with white space where needed. Default entries load their bundled stock photos. Each word is centered in the back answer panel using Poppins Regular at 25 pt, shrinking only when needed to fit; words too long to fit fail generation for review. The designer's raster /qu/ and /x/ lines are patched to /kw/ and /ks/ to agree with the survey. Page 3 uses the dedicated child photo, with a white Poppins Bold name curved above the dotted circle. Maximum type size is 48 pt and longer names shrink to a 112-degree arc. The approved arc centre is 3 mm above its original position; glyph-bound tests check descender clearance.

Output preserves bleed at 324 x 414 points and adds an explicit TrimBox inset 9 points (306 x 396 points = 4.25 x 5.5 inches). There are no crop marks. Canva's importer treated the first file's MediaBox as the design dimensions (432 x 552 Canva pixels), ignoring the trim size. Run `node scripts/prepare-canva-import.mjs source-bleed.pdf destination-canva.pdf` to create a separate finished-size import. This translates the original content by -9 points on each axis without scaling; the original bleed PDF remains unchanged. The verified Canva import is 408 x 528 Canva pixels (4.25 x 5.5 inches), 56 pages. Review Canva's print bleed and front/back ordering and obtain a physical proof before a production print order. This pilot is not a print purchase.

Rendering and storage run inside the existing private PDF-generation lease. The private PDF path and admin download behavior remain unchanged, including 90-day retention. No customer PDF is put on a public URL to import it into Canva.
